## 🐛 TROUBLESHOOTING

### Widget tidak muncul?
```
1. Refresh halaman (F5)
2. Clear cache (Ctrl+Shift+Delete)
3. Buka di browser lain
4. Check console (F12) untuk error
```

### AI tidak menjawab?
```
1. Cek spelling pertanyaan
2. Gunakan huruf kecil
3. Coba pertanyaan yang lebih spesifik
4. Tunggu 1 detik untuk response
```

### Chat history hilang?
```
1. localStorage belum diimplementasi untuk history
2. Refresh page akan reset chat
3. Belanja backend integration untuk persistent storage
```
